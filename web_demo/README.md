# PS9 浏览器 3D 演示

一个不需要 ROS、相机或 GPU 推理环境的独立浏览器演示。可旋转、缩放房间，切换俯视/透视，选择污渍，播放、暂停、重置或加速模拟清洁过程。桌面和手机均可使用。

**全部房间尺寸、污渍坐标、机器人造型、路线及清洁状态均为模拟数据。** 本演示不会运行 YOLO，不读取传感器，不发送机器人控制命令，也不代表定位精度或真实清洁效果。运动路线预先设定，未实现路径规划或避障。

## 本地启动

在项目根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory web_demo
```

浏览器打开 <http://127.0.0.1:8765>。不要直接双击 `index.html`，浏览器会限制本地文件的 JavaScript 模块加载。按 `Ctrl+C` 停止服务器。

需要支持 JavaScript 模块、import maps 和 WebGL 2 的现代浏览器。无须 `npm install` 或联网加载 CDN：固定版本 Three.js 0.180.0 和 OrbitControls 已附带于 `vendor/`，保留 MIT 许可证及来源/完整性信息。

## 操作

- 鼠标拖动 / 单指拖动：旋转；滚轮 / 双指缩放：调整距离；也有独立缩放按钮。
- 透视 / 俯视：切换观察方式。
- 点击污渍，或使用右侧目标列表：查看类别、编号、模拟地面位置及状态。
- 开始 / 暂停 / 继续：控制模拟过程；完成后可重新演示。
- 重置：回到当前布局的初始状态；重新布置：生成另一组确定性的模拟位置。
- 1× / 2× / 4×：调整播放速度。运行时间显示的是模拟时间；清理进度为已标记清理的目标数占比，并非地面覆盖率。

## 文件与后续接入

- `index.html`、`style.css`：界面、响应式布局和加载错误提示。
- `app.mjs`：Three.js 场景、视角、目标选取及界面绑定。
- `simulation.mjs`：独立模拟状态与预设路线。类别 ID 对应现有模型的 `0: bigdirt`、`1: dirt`、`2: water`，不把 `background` 作为污渍展示。
- `vendor/`：带许可证的 Three.js 依赖。

模拟数据用地面 X/Y 表示，单位约定为米；显示层映射为 Three.js 的 `(x, height, -y)`。这些数字没有经过相机标定，不能当作实测结果。

要接入现有 `/ps9/detections`，还需通过深度与相机标定，或已知地面平面与相机位姿，求取目标位置；跨帧地图还需要位姿、时间同步和目标关联。届时可以替换模拟数据入口，复用三维显示层。
