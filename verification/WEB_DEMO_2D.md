- `app.mjs`、`scene2d.mjs` 和 `simulation.mjs` 通过 Node.js 语法检查。
- 个人主页、CSS、共享 SVG 演示模块、模拟模块和检测图片均通过本机 HTTP 200 / 内容类型检查。
- Codex 内置浏览器中：2D 场景正常显示；播放、暂停、继续、目标选择、4× 加速、重置和重新布局均正常。
- 完整回放显示 `9 / 9 cleared`、`00:44`、`35.2 m` 与完成状态。
- 暂停后切换目标，时间、距离和计数保持不变。
- 390px 与 320px 视口的页面宽度等于可见宽度，无横向溢出。390px 的简介、工业经历、模拟场景与控制栏经截图检查。

- 页面对模拟场景与实际模型预测图进行了明确区分。未调用相机、推理模型或机器人控制接口。
